# Island Survival Game
Games for Change is a game jam lasting for three months to raise awareness about certain themes. Our team of four people made this game in three months as part of our game development club in our school. We used Godot to create the game and program all of its functionalities. 
Island Survival features include terrain generation, dynamic game ending, and an upgrade system powered by a shop. All of these are custom systems that we created using the Godot game engine.
